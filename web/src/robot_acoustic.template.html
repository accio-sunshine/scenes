Scene Simulator

Listening tests for a robot's microphone array

Build a scene around the robot's head (a room, up to five people and the noise of the place), then hear it the way its microphones do. The page measures how well each beamformer picks out every speaker, and checks those numbers against a fuller Python simulation of the same scene.
